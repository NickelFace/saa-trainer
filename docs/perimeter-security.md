# Защита периметра

Слой сервисов, которые ловят атаки, находят уязвимости и обнаруживают подозрительную
активность. В вопросах их различают по объекту защиты: трафик, аккаунт, данные,
инстансы и образы.

## WAF

Фильтрует HTTP-запросы на уровне 7. Подключается к CloudFront, ALB, API Gateway,
AppSync, Cognito user pool и App Runner — но не к NLB. Web ACL состоит из правил:

- managed rule groups от AWS и партнёров (OWASP Top 10, боты, известные плохие адреса);
- собственные правила по IP, стране, заголовкам, телу, длине, регулярным выражениям;
- rate-based rules ограничивают частоту с одного адреса — ответ на «слишком много
  запросов от одного клиента» и на layer-7 flood;
- Bot Control и Fraud Control (защита от подбора учётных данных и мошеннической
  регистрации);
- логирование в Firehose, CloudWatch Logs или S3.

Требование «блокировать SQL-инъекции и XSS» — WAF, а не security group и не NACL.

## Shield

Shield Standard включён всем бесплатно и защищает от типовых объёмных атак сетевого
и транспортного уровня. Shield Advanced (платный) добавляет расширенную защиту,
круглосуточную команду реагирования (SRT), защиту от финансовых последствий скачка
трафика, детальную видимость и интеграцию с WAF на управляемых правилах. Формулировки
«dedicated DDoS response team», «cost protection», «advanced DDoS» указывают на Advanced.

## GuardDuty

Непрерывное обнаружение угроз по данным CloudTrail, VPC Flow Logs, DNS-логов, а также
логов EKS, S3-событий, RDS-логинов, EBS-снапшотов (malware protection) и Lambda.
Включается за минуты, ничего не разворачивается на инстансах. Находит: майнинг
криптовалюты, обращения к C2-серверам, аномальные вызовы API, компрометацию учётных
данных, сканирование портов.

Формулировка «detect unusual activity», «compromised credentials», «no agents to
install» — GuardDuty. Реакция на находки автоматизируется через EventBridge и Lambda,
а централизованный обзор даёт Security Hub.

## Inspector

Сканирует уязвимости: EC2 (через агент SSM), образы в ECR и функции Lambda. Работает
непрерывно, сопоставляет пакеты с базой CVE, выдаёт оценку риска с учётом сетевой
достижимости. Ответ на «проверять образы и инстансы на известные уязвимости
автоматически».

## Macie

Ищет чувствительные данные в S3: персональные данные, номера карт, ключи доступа,
токены. Строит инвентарь бакетов с оценкой рисков (публичность, шифрование, доступ
извне). Формулировка «discover PII in S3» — всегда Macie.

## Security Hub, Detective, Config

- Security Hub агрегирует находки GuardDuty, Inspector, Macie, Config и партнёрских
  решений, проверяет соответствие стандартам (CIS, PCI DSS, AWS FSBP);
- Detective строит граф связей событий для расследования инцидентов;
- Config фиксирует конфигурации и правила соответствия, умеет авторемедиацию через SSM;
- CloudTrail фиксирует вызовы API и является источником доказательств.

## Network Firewall и DNS Firewall

AWS Network Firewall — управляемый stateful-межсетевой экран уровня VPC с правилами
Suricata, фильтрацией доменов и IPS. Разворачивается в inspection-VPC вместе с
Transit Gateway или GWLB. Route 53 Resolver DNS Firewall блокирует резолвинг
вредоносных доменов и мешает эксфильтрации данных через DNS.

Сравнение с security group и NACL: те работают на уровне ENI и подсети и не понимают
доменов, сигнатур и содержимого; Network Firewall понимает.

## Cognito

User pools — каталог пользователей приложения: регистрация, вход, MFA, восстановление
пароля, федерация с Google, Apple, Facebook, SAML и OIDC; выдаёт JWT, которые проверяет
API Gateway или ALB. Identity pools обменивают токен на временные ключи IAM для прямого
доступа к сервисам AWS. Типовой ответ на «нужна аутентификация пользователей мобильного
приложения и доступ к S3 от их имени».

## Что спрашивают на экзамене

1. «Веб-приложение под SQL-инъекциями» — WAF на ALB или CloudFront.
2. «Нужна команда реагирования и защита от счёта при DDoS» — Shield Advanced.
3. «Найти PII в бакетах» — Macie.
4. «Обнаружить компрометацию учётных данных без агентов» — GuardDuty.
5. «Проверять образы контейнеров на CVE» — Inspector с ECR.
6. «Централизованный обзор соответствия стандартам» — Security Hub.
7. «Ограничить число запросов с одного IP» — rate-based rule в WAF.
8. «Фильтровать исходящий трафик по доменам» — Network Firewall или DNS Firewall.

## Числа, которые надо помнить

- WAF подключается к CloudFront, ALB, API Gateway, AppSync, Cognito, App Runner,
  но не к NLB;
- rate-based rule считает запросы с одного IP за окно в 5 минут;
- GuardDuty включается за минуты и не требует агентов, находки уходят в EventBridge;
- Inspector сканирует EC2 через агент SSM, образы в ECR и функции Lambda;
- Macie ищет чувствительные данные только в S3;
- Shield Standard бесплатен, Advanced стоит фиксированно в месяц и даёт SRT
  и cost protection;
- Security Hub агрегирует находки, Detective строит граф расследования.

## Как читать формулировку

| В тексте вопроса | Ответ |
|---|---|
| «SQL injection, XSS, OWASP» | WAF с managed rules |
| «dedicated DDoS response team, cost protection» | Shield Advanced |
| «detect compromised credentials, no agents» | GuardDuty |
| «find PII stored in S3» | Macie |
| «scan container images for CVEs» | Inspector |
| «single view of compliance across accounts» | Security Hub |
| «limit requests per IP» | rate-based rule |
| «inspect and filter egress traffic by domain» | Network Firewall или DNS Firewall |

## Реакция на инциденты

Типовой автоматический контур: GuardDuty находит угрозу → событие в EventBridge →
Lambda или SSM Automation изолирует инстанс (заменяет security group, снимает
снапшот, отзывает сессии роли) → уведомление в SNS → находка попадает в Security Hub.
Для расследования привлекают Detective, CloudTrail и VPC Flow Logs, для восстановления —
снапшоты и AWS Backup. В вопросах ищите вариант, где реакция автоматизирована и не
требует, чтобы дежурный вручную заходил в консоль.

## Мини-практикум

**1.** Публичный API атакуют перебором с одного диапазона адресов.
→ WAF с rate-based rule и правилом по IP на CloudFront или ALB.

**2.** Служба безопасности требует находить утечки персональных данных в бакетах.
→ Macie с регулярными заданиями обнаружения и находками в Security Hub.

**3.** Требуется обнаружить майнинг и обращения к C2-серверам без установки агентов.
→ GuardDuty на всех аккаунтах организации с делегированным администратором.

**4.** Нужно запретить исходящие обращения к доменам вне списка разрешённых.
→ AWS Network Firewall с фильтрацией доменов или Route 53 Resolver DNS Firewall.
